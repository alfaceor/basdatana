# BASic DATa ANAlysis

The objective of this repository is to provide basic examples and cases to make a proper data analysis using R and/or python.

## What do we care about?

- How to establish if data is good, proper and clean?
- Do we have enough sample data to determine valid conclusions for the population?
- How to make data processes reliable, reproducible, and easy to acces?
- How to visualize complex multidimensional information to obtain clear insights and intuitions?
